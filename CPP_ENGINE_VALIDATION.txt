Measured performance
  Body + 478-point face motion calculations: Python 966.85us/update,
  C++ 308.30us/update — 3.14× faster over 240 equal-output frames.
  Same-camera-frame model adapter inference median: Python
  68.486ms, C++ 62.900ms (55 samples after 5 warmup frames).
  These are measurements on this computer, not a promise of 3× whole-app FPS
  or an accuracy evaluation. The neural inference runtime was already native;
  the migration reduces capture/wrapper/object-conversion/movement overhead.
